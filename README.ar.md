# Mycelium
Mycelium — طبقة السجل الخاصة بكل مشغّل، المشهود عليها، الإضافيّة فقط (append-only)، لشبكات العمارة ذات الوجهين (Janus-Facing Architecture) (NTARI). مواصفة + تنفيذ مرجعي بلغة JS. AGPL-3.0.
